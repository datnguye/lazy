# lazy

> Lazy is not lack of awareness, it is full context awareness. Less, and shipped.

<img src="assets/logo-dark.svg" alt="thug life" width="150">

Too lazy to write the pitch, so here is the important part: your agent stops
over-engineering. YAGNI, stdlib first, native over dependencies, the shortest
diff that works.

Authored once, rendered into n agent formats. Writing the same prompt n
times would be, of all things, not lazy.

## Install

- Claude Code, from its prompt:

```
/plugin marketplace add datnguye/lazy
/plugin install lazy@datnguye
```

GitHub Copilot CLI, from your shell:

```bash
copilot plugin marketplace add datnguye/lazy
copilot plugin install lazy@datnguye
```

Both ship the same 3 skills and activate lazy mode on every new session, so
you can forget it is there — which is the whole point.
